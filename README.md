# ludo-sultan-privacy
Privacy policy for the Ludo Sultan Android game.

The official, always up to date version of this policy is at https://ludosultangame.com/privacy

This GitHub Pages copy is kept so older links keep working. It has the same text as the official page.

## Account & data deletion

Delete in the app: **Account, then Delete account** (instant; removes account, cloud save, profile, friends, DMs, club and event scores from the server). Without the app: email support@ludosultangame.com with subject "Ludo Sultan data deletion" and your account email or friend code. Data is deleted within 30 days. Details: https://ludosultangame.com/privacy#delete
